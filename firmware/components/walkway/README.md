# Experimental straight mapping

This is an isolated, incomplete experiment. It is not compiled into firmware,
not exposed in the replay helper, and does not implement the issue's settings,
tracking, validation, or user interface. Do not use it to configure hardware.
Its tests run against the production LD2450 parser and this experimental mapper,
not the production input-to-LED boundary. The interpretation and tests must be
reconciled with that boundary before this can satisfy the straight walkway issue.
